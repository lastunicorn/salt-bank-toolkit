
# Salt Bank Toolkit

A set of helpers to interact with files generated by Salt Bank.

Salt Bank is a Romanian bank: https://en.wikipedia.org/wiki/Salt_Bank

## NuGet Package

```
Install-Package DustInTheWind.SaltBank.ToolKit
```

Or via the .NET CLI:

```
dotnet add package DustInTheWind.SaltBank.ToolKit
```

## Statement Files

### Step 1 - Export CSV Statement File

Go to the Salt Bank mobile application and export account statements as CSV files.

At this moment, the files should have the following header line:

`Date,Counter Party,Reference,Type,Amount (RON),Balance (RON),Spending Category,Notes`

> **Note**: The currency `RON` will be different if the export was done from another currency account.

### Step 2 - Parse the File

The `StatementsDocument` class provides several methods to parse and load a CSV file, to accommodate different input sources. Here it is one of them:

**From a file path:**

```csharp
StatementsDocument doc = StatementsDocument.LoadFile("statement.csv");
```

### Step 3 - Use the Data

`StatementsDocument` is a collection of `BankTransaction` objects and also exposes the detected currency:

```csharp
Console.WriteLine($"Currency: {doc.Currency}");

foreach (BankTransaction transaction in doc)
    Console.WriteLine($"{transaction.Date} | {transaction.CounterParty} | {transaction.Amount}");
```

## `BankTransaction` Properties

| CSV Column          | Property           | Type       | Description                                      |
|---------------------|--------------------|------------|--------------------------------------------------|
| `Date`              | `Date`             | `DateOnly` | The date when the transaction occurred.          |
| `Counter Party`     | `CounterParty`     | `string`   | The name of the other party in the transaction.  |
| `Reference`         | `Reference`        | `string`   | A reference identifier for the transaction.      |
| `Type`              | `Type`             | `string`   | The type/category of the transaction.            |
| `Amount (RON)`      | `Amount`           | `double`   | The transaction amount (positive or negative).   |
| `Balance (RON)`     | `Balance`          | `double`   | The account balance after the transaction.       |
| `Spending Category` | `SpendingCategory` | `string`   | The spending category assigned to the transaction.|
| `Notes`             | `Notes`            | `string`   | Additional notes associated with the transaction. |

> **Note:** The currency (e.g. `RON`) is automatically detected from the column headers and exposed via the `StatementsDocument.Currency` property.

## Error Handling

The library throws the following exceptions:

| Exception                   | Description                                                              |
|-----------------------------|--------------------------------------------------------------------------|
| `StatementDocumentException`| General error while loading or parsing the document.                    |
| `StatementHeaderException`  | A required CSV header column is missing or invalid.                     |
| `StatementDataException`    | A data row contains an invalid or unparseable value.                    |

## Requirements

- .NET 8.0 or later
- [CsvHelper](https://joshclose.github.io/CsvHelper/) (included as a dependency)
