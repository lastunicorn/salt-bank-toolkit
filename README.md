# Salt Bank Toolkit

A set of helpers to interact with files generated by Salt Bank.

## Statement Files

### Step 1 - Export CSV Statement File

Go to Salt Bank application and export statement files as CSV files.

At this moment, the files have the following header column:

`Date,Counter Party,Reference,Type,Amount (RON),Balance (RON),Spending Category,Notes`

### Step 2 - Parse the File

```c#
StreamReader streamReader = File.OpenText("statement.csv");
StatementsDocument doc = StatementsDocument.Load(streamReader);
```
